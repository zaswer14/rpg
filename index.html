Kho RPG

Các dự án game nhập vai dùng chung một phần lõi: cơ chế nghề, chủng tộc, giáo phái, quái, tên riêng, địa hình và luật chung. Mỗi game là một thư mục riêng; các trang duyệt nội dung nằm tách ra. Bản đồ kho cho người làm: TRA_CUU.md.

Công cụ

tools/

Chạy bằng bash (Git Bash trên máy tính) trừ server.

  • sync.shđồng bộ GitHub đầu / cuối phiên
  • muc_luc.shmục lục theo dòng của file lớn
  • duyet.shtrang duyệt có theo kịp dữ liệu không
  • serve.ps1server tĩnh cổng 8765

Trang cần chạy qua server (powershell -ExecutionPolicy Bypass -File tools/serve.ps1, rồi mở http://localhost:8765/) vì các game nạp ../shared/*.js.
